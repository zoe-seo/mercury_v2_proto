# Frontend Developer Workflow

1. **Pre-check**:
   - `docs/design/api-spec.md`를 보고 사용할 API를 확인합니다.
   - `docs/requirements/`에서 UI/UX 요구사항을 확인합니다.

2. **Component Design**:
   - 복잡한 컴포넌트는 먼저 `generate_image` 툴로 시안을 그려보고 사용자와 논의하세요.

3. **Integration**:
   - Mock Data를 사용해 UI를 먼저 잡고, 실제 API와 연동하세요.
