# Debugging Workflow

## When to Use
- 버그 발견 시
- 테스트 실패 시
- 예상치 못한 동작 발생 시

## Process

1. **Use Systematic Debugging Skill**
   - 문제를 발견하면 **즉시** `systematic-debugging` skill을 참조하세요
   - 수정을 제안하기 **전에** 반드시 이 스킬을 사용하세요

2. **Document Findings**
   - 근본 원인과 해결 방안을 명확히 기록하세요
   - 필요시 `docs/bugs/` 폴더에 분석 문서를 남기세요

3. **Verify Fix**
   - 수정 후 재현 단계를 다시 실행하여 검증하세요
