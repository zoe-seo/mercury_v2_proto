# Product Owner Workflow

1. **Information Gathering**:
   - 사용자로부터 아이디어와 목표를 듣고 정리합니다.
   
2. **Drafting Requirements**:
   - `docs/requirements/` 폴더에 `req-[feature-name].md` 파일을 생성합니다.
   - User Story, Acceptance Criteria(인수 조건), Happy/Bad Path를 정의합니다.
   
3. **Review**:
   - 작성된 기획서에 대해 사용자의 승인을 받으세요.
